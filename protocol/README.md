# The host Agent in C#

Generated by the AdHoc protocol generator.

## Build and run

```
dotnet run
```

## What is here

| In this folder | What it is |
|:--|:--|
| `gen` | the generated protocol code. Every generation writes it anew: your code goes into the regions it has marked |
| `lib` | the AdHoc runtime library |
| the demo | a skeleton of the host: every method you have to provide. Start from it |
| `Project.csproj`, `nuget.config` | what builds this folder as a project of its own |

## In your project

The first generation writes `<description>.md` beside the description. Write next to each host folder in it the folder of your project it
goes to, then run `AdHocAgent <description>.md`. `gen` and `lib` always go with the host folder and keep their place in it: add them to the
source folders of your build. The demo and the project files go only when you ask for them there.

## Encryption

`Project.csproj` downloads `AdHoc.Crypto.nupkg` from the latest release of adhoc-crypto into `obj/adhoc-crypto` at the first restore. `dotnet build` and `dotnet publish` lay the native library out. A project of your own: the head of `lib/Chain.cs`. With no chain and no key the library is not loaded.

The whole guide: [MANUAL.md](https://github.com/AdHoc-Protocol/AdHoc-protocol/blob/main/MANUAL.md).
